Основная цель данного проекта — предоставить детальное руководство по созданию полнофункционального "Сервиса Агрегации Логов и Оповещений". Реализация этого проекта позволит специалисту освоить практические навыки DevOps на уровне Middle, что является необходимым условием для успешного трудоустройства на соответствующие позиции (DevOps Engineer, Support Engineer) в израильском хайтек-секторе с целевым уровнем заработной платы свыше 32 000 шекелей в месяц.

Проект представляет собой систему, построенную на основе микросервисной архитектуры. Его ключевые функции включают сбор (ingestion), обработку, хранение и анализ лог-данных с последующим формированием оповещений при обнаружении аномалий или заданных событий. Такая система является типичным примером инструментов обеспечения наблюдаемости (observability), которые критически важны для поддержания надежности и производительности современных IT-систем. Работа над этим проектом имитирует реальные задачи, с которыми сталкиваются DevOps-инженеры, инженеры по надежности сайтов (SRE) и специалисты технической поддержки в повседневной деятельности.
